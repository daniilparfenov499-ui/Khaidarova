# Дневник головной боли

Android-приложение на **Kotlin + Jetpack Compose** для записи приступов головной боли, поиска триггеров и подготовки отчёта для врача.
Автор: Хайдарова Мария, группа ПДОП-34.

## Проблема
Пациенту трудно вспомнить на приёме, сколько было приступов и что им предшествовало. Бумажные дневники неудобны, а триггеры (сон, стресс, еда, погода) без статистики не видны.

## Возможности
- **Запись приступа** за ~30 секунд: время, сила боли 1–10, длительность, симптомы, триггеры, лекарство и его эффект, заметка.
- **История** записей с возможностью удаления.
- **Ежедневная отметка** сна, стресса, кофе и воды.
- **Статистика:** приступы по неделям, средняя боль и длительность, частые триггеры, связь сна и приступов, эффективность лекарств.
- **Отчёт для врача** за 7/30/90 дней с отправкой текстом через любое приложение.
- **Напоминания** (отметка дня, лекарство, вода) через WorkManager.
- Все данные хранятся **только на телефоне** (Room / SQLite), без регистрации и интернета.

## Технологии
Kotlin 2.0 · Jetpack Compose (Material 3) · Navigation Compose · Room · WorkManager · архитектура MVVM (ViewModel + Flow).
minSdk 26 (Android 8.0), targetSdk 34.

## Как собрать
1. Установите **Android Studio** (Koala 2024.1 или новее).
2. `File → Open` и выберите эту папку. Дождитесь Gradle Sync (нужен интернет).
3. Запуск на устройстве/эмуляторе: кнопка ▶ Run.
4. **Сборка APK:** `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
   Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.
   Из терминала (после синхронизации в Android Studio): `./gradlew assembleDebug`.

## APK в репозитории
Скопируйте `app-debug.apk` в папку `apk/` (в корне репозитория) **или** приложите его к релизу на GitHub:
`Releases → Draft a new release → тег v1.0 → прикрепить app-debug.apk → Publish`.
